Синхронизация (вход по почте)

Создайте аккаунт по почте и паролю — и дневник будет доступен с любого устройства. Этим же приложением могут пользоваться другие люди: каждый со своим аккаунтом.

Как настроить (5 минут, бесплатно)
  1. Открой console.firebase.google.com → «Create project» (любое имя, аналитику можно отключить).
  2. Build → Authentication → Get started → Sign-in method → Email/Password → Enable → Save. (Хотите и кнопку Google — там же включите Google.)
  3. Build → Firestore Database → Create database → «Start in production mode» → регион любой.
  4. Вкладка Rules (правила) — замени текст на правила ниже и нажми Publish:
  5. Вернись на главную проекта → Project settings (шестерёнка) → внизу «Your apps» → иконка Web «» → задай имя → скопируй объект firebaseConfig.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write:
        if request.auth != null
        && request.auth.uid == uid;
    }
  }
}
  • Вставь firebaseConfig в поле «Конфигурация Firebase» в приложении и нажми «Сохранить конфиг». Затем войдите по почте — прямо в приложении.
    • Данные хранятся только в вашем Firestore — доступ только у вашего Google-аккаунта.
    Распознавание еды по фото (Gemini)
    Ключ нужен только для функции «Фото блюда»: фотографируешь тарелку — приложение само распознаёт блюда, вес и КБЖУ. Бесплатный ключ: aistudio.google.com/apikey (Google AI Studio). Ключ хранится только на вашем устройстве.
    Данные
    Все записи хранятся в этом браузере/телефоне (офлайн). Очистка данных браузера или кнопка «Удалить» может стереть дневник — делайте экспорт для резервной копии.
    Приложение на телефон
    Проверка API ключа
    Вставьте API ключ и напишите сообщение — убедитесь, что он работает. Если API запрещает вызовы из браузера (CORS), запрос автоматически пойдёт через встроенный прокси сайта.
